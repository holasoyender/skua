
# skua - a fork of serenity with extra utilities

This is a fork of [Serenity](https://github.com/serenity-rs/serenity) with extra stuff.

### Important!
Please note that this is still a experimental fork, and it's not recommended to use it in production.

### Why?
Well, its a personal thing, I love this library, but I don't like the way it handles stuff like sending or replying to messages, components, etc...
This fork aims to make it easier to use, and more user-friendly. I also come from [JDA](https://github.com/discord-jda/JDA) (and [jda-ktx](https://github.com/MinnDevelopment/jda-ktx))
and I'm used to the way it handles stuff, so I'm trying to make it more similar to that.
